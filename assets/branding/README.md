# Logo oficial da Vibe

Coloque nesta pasta a logo oficial com o nome `vibe.png`, preferencialmente
PNG com fundo transparente. A imagem sera versionada no Git e recebida no
Raspberry pelo `atualizar.sh`, junto com o projeto.

O aplicativo usa essa imagem automaticamente, sem precisar criar configuracao
local. A logo e obrigatoria nos novos replays e permanece no centro inferior.

As logos locais de patrocinadores podem continuar em `config/branding/`, com
os caminhos definidos em `config/branding.json`.
